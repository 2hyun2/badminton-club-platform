# 배드민턴 동호회 플랫폼

여러 배드민턴 동호회가 회원, 게스트, 출석, 경기, 기록, 회비와 공개 홈페이지를 관리할 수 있는 웹·앱 플랫폼의 기획 및 설계 기록입니다.

## 현재 단계

Next.js 웹을 먼저 구현하기 전, Obsidian Markdown으로 사용자 흐름, 디자인 시스템, 데이터 모델, 인프라와 수익화 방향을 설계하고 있습니다.

## 문서

- `00 프로젝트 홈.md` — 프로젝트 개요와 문서 진입점
- `01 디자인 시스템.md` — 색상, 여백, 컴포넌트와 알림 화면 규칙
- `02 UI 화면 흐름.md` — 로그인, 다중 동호회, 게스트 흐름

- `04 개인정보 및 게스트 양식 정책.md` — 게스트 개인정보 및 양식 기준
- `05 구현 로드맵.md` — Next.js → Express → React Native 구현 순서

- `10 게스트 페이지 설계.md` — 비회원 게스트 흐름

- `13 알림 데이터 설계.md` — 개인 알림·동호회 공지·읽음 처리 구조

## 방향

- 앱 회원과 동호회는 별개의 데이터이며, 한 회원은 여러 동호회에 소속될 수 있습니다.
- 비회원 게스트 신청은 정식 가입과 분리하며, 개인정보는 운동 종료 뒤 7일간만 보관합니다.
- 기본 동호회 운영 기능은 무료로 제공하고, 규모 확장·선택 기능·홈페이지 맞춤 제작으로 수익화를 검토합니다.
- 초기에는 웹 알림함을 제공하고, React Native 단계에서 휴대폰 푸시 알림을 추가합니다.

## 예정 기술 구성

```text
Web: Next.js
API: Node.js + Express + Socket.IO
Database: PostgreSQL
Mobile: React Native
Infrastructure: AWS (서울 리전)
```
